Gli appunti in Markdown sono indicati dall'estensione file `.md`, sono molto simili a dei file di testo, ma supportano HTML/CSS (per stilizzare il documento) e $\LaTeX$ (per scrivere matematicamente). Non è necessario scaricare un file Markdown per leggerlo, GitHub offre un visualizzatore di questo tipo di file in tempo reale (il documento che stai leggendo è scritto in Markdown). Oltre ad essere visivamente più semplice di un documento vero e proprio, i Markdown si adeguano al tema del browser di Internet (utile per chi ha attivato il tema scuro). Inoltre, aprire un file Markdown e cliccare sul tasto *Raw* in alto a destra nel browser dei file mostra il codice sorgente del documento. È possibile quindi modificarlo per creare una propria versione degli appunti con un apposito editor Markdown. I file `.pdf` sono i soliti documenti stampibili che tutti conosciamo, sono molto più belli e ordinati dei Markdown, utili per chi predilige le copie stampate del proprio materiale di studio. Anche i `.pdf` sono consultabili direttamente su GitHub, ma il visualizzatore non consente lo schermo intero. È possibile scaricare un `.pdf` e consultarlo sul proprio dispositivo aprendolo e cliccando sull'icona con la freccia in basso (↓). Per la mia comodità, troverete anche dei file `.pdf` a tema scuro nella cartella *PDF Dark*, organizzata analogamente alle principali.

# Quando usare questi appunti 😊

Confido nel tuo senso di responsabilità sperando che continuerai a prendere i tuoi appunti di tua sponde. Sconsiglio di affidarsi completamente ai miei appunti perché prenderne di propri in classe aiuta la comprensione dell'argomento, perché richiede comunque uno sforzo cognitivo schematizzare e scrivere ciò che si ritiene più importante. Va da sé che questi appunti non sono sostituibili ai libri di testo, soprattutto nel caso delle materie umanistiche, pertanto consiglio di utilizzarli come supporto al libro scolastico. Usa questi appunti solo se non hai potuto prenderne di tuoi oppure se ritieni che i tuoi siano incompleti. Continua comunque a prenderne di tuoi, migliora la tua tecnica, così non dovrai fare affidamento su nessuno. Ovviamente, ognuno studia e prende appunti a modo proprio. Se il mio metodo di studio non è conforme al tuo metodo di apprendimento, non c'è motivo di ostinarsi a imparare con i miei appunti.
